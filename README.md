# Marketing Performance Analysis Dashboard | Power BI

![Marketing Performance Dashboard](Screenshot%202026-06-12%20022717.png)

## Project Overview

This project presents an interactive **Marketing Performance Analysis Dashboard developed using Microsoft Power BI** to analyse marketing effectiveness, revenue performance, customer engagement, and campaign efficiency.

The dashboard converts raw marketing data into actionable insights by tracking key performance indicators such as revenue, spend, impressions, clicks, conversions, ROI, CTR, and CPC.

The objective of this project is to provide stakeholders with a centralised business intelligence solution for evaluating marketing strategies, optimising campaign performance, and improving data-driven decision-making.

---

## Business Problem

Marketing teams generate large amounts of campaign data across multiple channels, products, and regions. Without effective analytics, businesses struggle to identify which marketing activities deliver the highest returns.

This project addresses the following questions:

- Which marketing channels generate the most revenue?
- Which products contribute the highest sales value?
- How efficiently is marketing spend being utilised?
- Which regions perform best?
- How do campaign results change over time?

The dashboard provides visibility into marketing performance and supports strategic planning.
